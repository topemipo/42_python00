# Growing Code

This project is an introduction to Python using simple community garden examples.

It guides us through the basics of writing small functions that handle input and output directly. Each exercise focuses on one fundamental idea, such as printing text, reading user input, using variables, doing calculations, checking conditions, looping, recursion, and adding type annotations.

The goal of the project is to build confidence with Python syntax and understand how simple programs are structured before moving on to larger projects.
